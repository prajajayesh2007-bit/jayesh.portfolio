## 🌟 Key Features

### 1. 🎮 Interactive 3D Quantum Silicon Microchip
- Built with **Three.js WebGL**:
  - Rotating 3D silicon chip substrate with 24 physical metallic pins.
  - Glowing CPU die core with cybernetic circuit wireframe overlay.
  - 3D orbital holographic rings.
  - Full mouse tilt and click-and-drag 360° free rotation.

### 2. 🌌 3D Cybernetic Particle Space
- Fullscreen WebGL space with 180+ depth particles and floating 3D wireframe cyber polyhedra.
- Stereoscopic camera parallax that responds smoothly to mouse motion.

### 3. 🧪 The ECS Digital Logic Gate Lab
- Hands-on interactive logic gate simulator (AND, OR, XOR, NAND, NOR, NOT).
- Real-time Boolean formula calculation and circuit wire propagation (+5V HIGH vs 0V LOW).
- Glowing 3D neon cyan LED output and dynamic Truth Table row highlighting.

### 4. 🛠️ Featured ECS Hardware & Software Projects
- **IoT Smart Environmental & Air Quality Monitor** (ESP32, MQ-135, DHT22, WebSockets, Chart.js)
- **Edge Computer-Vision Gesture-Controlled Rover** (Python OpenCV, MediaPipe, Arduino Uno, L298N)
- **Smart Contactless RFID Campus Access System** (ESP8266, RC522 RFID, Node.js, SQLite, OLED)
- **Web-Based Digital Logic & Micro-Op Simulator** (Combinational logic, TTL 7400 series)

### 5. 🎴 Gyroscopic 3D Card Tilt with Specular Glare
- Physical 3D perspective tilt effect on all project, skill, and education cards.
- Dynamic specular sheen overlay that follows virtual light reflection.

## 🛠️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/prajajayesh2007-bit/jayesh.portfolio.git
   cd jayesh.portfolio
   ```

2. Open `index.html` directly in any web browser, or run a local static server:
   ```bash
   # Using Python 3:
   python -m http.server 8080

   # Or using Node:
   npx serve .
   ```

3. Navigate to `http://localhost:8080`.
